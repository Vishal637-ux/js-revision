# 🌾 Agri Mitra

Smart Agriculture Assistant built using HTML, CSS, and JavaScript.

---

# 📌 Project Vision

Agri Mitra is a smart farming platform that helps farmers using technology.

The goal is to create a simple and user-friendly agriculture website that provides:

- Weather updates
- Crop recommendations
- Market prices
- Government schemes
- AI chatbot interface
- Voice assistant UI

This project starts with frontend development using HTML, CSS, and JavaScript and later upgrades into a MERN + AI platform.

---

# 🎯 Main Goal

Learn real frontend development by building a complete agriculture project step-by-step.

---

# 🛠 Tech Stack

## Frontend

- HTML5
- CSS3
- JavaScript

## Future Upgrade

- React.js
